# Inspiration (non-normative)

Experimental wireframes, HTML prototypes, JSX snippets, and styling experiments live here **for reference** while sketching UX.

Material in **`_inspiration/`** is **not** product specification unless work is lifted into:

- **`docs/epics/`** or **`docs/features/`** intent and contracts, and/or
- **`docs/milestones/<version>/`** stories with explicit requirements and acceptance criteria.

When something graduates from experimentation to **what we ship**, mirror the behavior in **`CONTEXT.md`** if new domain vocabulary appears.
