# F-005: Session & Phase Tracking

Structure play into **sessions** (one visit to the app) and **phases** (narrative units combining exploration and optional combat). Track flip counters per phase.

## What it does

- **Start a new session** — within an existing campaign, begin a play instance
- **Create/move through phases** — play one or more phases in a session
- **Track counters** — exploration and combat counters per phase (player-controlled)
- **Show phase progress** — visual display of flips used, narrative momentum
- **Session recap** — summary of what happened (flips made, phases completed, key moments)
