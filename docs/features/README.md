# Features — Core Capabilities

**Altitude:** durable **what** — systems boundaries, integrations, contracts, and links to **`CONTEXT.md`** and **ADRs** when a decision qualifies.

Features live **outside** milestone folders — they describe capabilities that persist across releases.

## Core Features

### [F-001: Campaign Management](./F-001-campaign-management.md)
Create, list, resume, pause, and delete **campaigns**. Each campaign holds its own deck, journal, and world details.

### [F-002: Card Flip & Oracle Lookup](./F-002-card-flip-oracle-lookup.md)
Flip the virtual deck and instantly resolve the card to a prompt via an **oracle table**. Player chooses which oracle (exploration, combat, settlement, yes-no, etc.). Each flip consumes one card and is recorded.

### [F-003: Narrative Journaling](./F-003-narrative-journaling.md)
Capture what you imagined after each flip. Journal entries store narrative prose, quick notes, and optional voice memos. Build your campaign archive entry by entry.

### [F-004: World-Building Persistence](./F-004-world-building-persistence.md)
Record NPCs, settlements, locations, factions, and relationships discovered during play. Retrieve and edit them between flips to keep world details in one place.

### [F-005: Session & Phase Tracking](./F-005-session-phase-tracking.md)
Structure play into **sessions** (one visit to the app) and **phases** (narrative units combining exploration and optional combat). Track flip counters per phase to show momentum.

### [F-006: Import & Export](./F-006-import-export.md)
Backup, share, and transfer campaigns. Users own their data and can export/import between devices or share with others. No cloud sync—all data is local and user-controlled.
